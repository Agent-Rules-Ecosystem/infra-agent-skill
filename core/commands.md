# ⚡ Comandos de Infrastructure & DevOps Agent Skill (`infra-agent-skill`)

| Comando | Acción | Descripción |
|---|---|---|
| `$infra` | Bootstrap | Bootstrap de la habilidad transversal de infraestructura. |
| `$infra:check` / `$infra:audit` | Diagnóstico | Diagnóstico integral de compuertas CI/CD, release hardening, empaquetado e IaC. |
| `$infra:hardening` | Release Hardening | Auditoría de optimización, minificación, dead code elimination y preservación/archivo de símbolos. |
| `$infra:cicd [target]` | CI/CD Pipelines | Creación/refactorización de workflows con contratos de compuertas pre-flight agnósticas. |
| `$infra:docker [target]` | Containerización | Generación/optimización de Dockerfiles multi-stage con separación estricta de capas. |
| `$infra:iac` | Provisionamiento | Manifiestos idempotentes de Terraform / Ansible con estado remoto seguro y locking. |
| `$infra:deploy` | Despliegue Seguro | Plan y ejecución de despliegue según arquetipo con verificación post-flight agnóstica. |
| `$learnskill infra-agent-skill [propuesta]` | Aprendizaje | Registrar propuesta de mejora específica para `infra-agent-skill` en `overview/learning.md`. |
| `$revlearnskill` | Revisión | Clasificar e inspeccionar propuestas de aprendizaje acumuladas en `overview/learning.md`. |
